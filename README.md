Es un programa que permite la fácil gestión de tus gastos financieros en el día a día, permitiendo así el control de tu
dinero y en que normalmente lo inviertes. 
## Funciones
- Agregar gastos (categoría, descripción y monto)
- Ver la lista de gastos
- Ver el total gastado
- Validación de entradas con try/except

 ## Cómo ejecutarlo
  python index.py
